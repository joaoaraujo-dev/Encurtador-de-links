# Encurtador-de-links
Um encurtador de links simples e direto com design moderno

## Descrição do projeto
Encurtador de links simples com design moderno, rapido e de facil uso, foi feito com PHP 8+ e utiliza o banco de dados MySQL, tem responsividade com varias telas

## Funcionalidades
- **Encurtamento rapido:** capaz de gerar um link curto sem precisar de ter uma conta
- **Redirecionamento otimizado:** redirecionamento rapido e seguro
- **Design responsivo:** o site possui responsividade para varias telas 

## Tecnologias utilizadas
- PHP
- HTML 5
- CSS
- BOOTSTRAP 5
- Material Symbols (Google)
- MYSQL

## Banco de dados
o projeto utiliza MySQL, na pasta `database` tem um arquivo `database.sql` responsavel por fazer a tabela principal do encurtador

## Requisitos
### Para rodar o projeto e necessario:
- Servidor Web (Apache ou Nginx)
- PHP 8+
- MySQL
